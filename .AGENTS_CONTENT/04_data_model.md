# 数据模型

## 标准 batch 契约

（`motus_model_batch_v1`，`libs/motus-data-factory/docs/BATCH_CONTRACT_V1.md`）`first_frame [B,C,H,W]`、`video_frames [B,T,C,H,W]`、`action_sequence [B,action_chunk,action_dim]`、`initial_state [B,state_dim]`，外加 `first_frame_pils`/`t5_input_messages`/`vlm_input_messages`（`vlm_inputs`/`language_embedding` 恒 None，模型侧现算）和元数据（`robot_names`、`source_datasets`、`action_loss_weights`/`video_loss_weights`/`state_action_policies`——**逐源常量**（adapter 配置），非 manifest 逐记录值；periodic_eval 侧 20260819 起扩展取值 `placeholder`=借位占位：零 state 仅锚点、action 照常预测但无 GT 对比，见 `06_periodic_eval.md`）。

## 运行时数据：Episode Catalog + 动态 SamplePool

Catalog 是 split-neutral episode 级索引（JSONL + SQLite 偏移索引；集群冻结 release：agibot_beta `20260723_concise_v2`、其余 9 源 `20260727_full_v1`，默认根 `/data/jiyuan.wang/EpisodeCatalogs`）；SamplePool 唯一内建 `sampling_ranges`：每 Episode 有效窗口起点区间 + ratio + 文本载荷（`text_payload`：`fixed` = 固定文本索引（libero 等单指令源；旧库另有 `agibot` 单片段 kind，仍兼容）；`segmented` = 分段文本族 episode context + 片段区间表，起点域为片段覆盖并集、运行时按窗口正重叠选全部重叠片段；零片段但有 context 的 episode 回退 `fixed` 不裁剪（egoverse aria×3/eva 仅 task 的真实形态，20260819 拍板），四族与拼装规则见 `03_config.md`"分段文本族"条）+ `layout` + `episode_len`（变倍率库另有 `max_stride` 列，见 `03_config.md` 窗口布局节）存 SQLite sidecar（`<catalog>.ranges.sqlite`，构建期剔除无有效窗口/文本的 episode），运行时 `SamplingRangesPool` 按 (seed, epoch, index) 内存确定性生成窗口索引（`video_frame_indices`/`state_indices`/`action_indices`/`text_indices`，robotmind 英文指令在 `text_indices` 选；分段文本族的 t5 文本由 motus_data composer 按源拼装，见 `batch_adapters._compose_t5_text`）。batch 另带 `frame_indices`（视频帧原始索引）——20260815 固定 5fps 轮起模型不再消费（变 FPS 条件已随 `models/fps_condition.py` 一并删除），仅作监控 meta/训练切片记录透传。

接入新源：转换脚本生成 manifest → `libs/motus-data-factory/tools/build_episode_catalog.py` 建 catalog → `data_prepare/build_sampling_ranges.py` 建 ranges → YAML 注册 `pool` spec。动作幅值 guard 阈值/源列表在 `motus_data/releases.yaml` 按 release 注册（agibot_beta 等 100.0）。各机器人动作维度/名称别名在 `dataset.robot_names`。

## action/state 归一化与动作目标表示

（模型边界，逐机器人）归一化策略由 `model.wm.action_norm_policy` 选择（20260811 起两套；统计量来自 `models/action_stats.py` 烘焙的 `ACTION_STATS`，由 `data_prepare/compute_action_stats.py` 在 H 集群 train split 上 reservoir 采样 + [0.5%, 99.5%] 分位数内重算 trimmed 统计产出，JSON 在集群 `training_dataset_config/action_stats/`，烘焙为手动拷贝；20260815 起 profile/归一化绑定 catalog 如 agibot_beta effector profile 经 release `reader_options` 自动解析，与 `build_sampling_ranges.py` 同款逻辑，且统计跳过 reader 数值质量策略排除的 episode 并计数；已重算烘焙 agibot-beta-parallel-gripper 与 egoverse-eva-bimanual 的夹爪边界，robotmind×4 为本机 micro subset 暂行值。20260816 量纲一致改造：agibot-beta 两 profile 条目增烘焙 `reader_z_mean`/`reader_z_std`（native_zscore_v1 artifact 的物理常量：pos 米 / rotvec 弧度 / 夹爪 mm），B3 策略先整向量逆变换还原物理量纲再做夹爪 min-max——与 egoverse 等 raw 物理源量纲一致；parallel-gripper 的 `q_low`/`q_high` 同步由 z 空间换算为物理 mm（≈[34.5, 123.0]）。注意这使 agibot-beta 的 pos/rot 训练数值尺度从 z 空间变为物理空间，属有意语义变化）：

- **`zscore`（默认，旧行为）**：全维 per-robot `(x-mean)/std`（`normalize_batch`/`denormalize_batch`），flow matching 与损失全程单位尺度；未注册机器人（如 robotmind）恒等。数据侧 agibot/agibot_beta 在 reader 内做 eef z-score（`AGIBOT_ACTION_MEAN/STD`），模型边界统计是其上的二次归一化。
- **`gripper_hand_minmax`（B3，对齐 MotusBrain 论文）**：仅夹爪/灵巧手维归一化 [-1,1]（dim_map 落入 `*_gripper`/`hand_*` band 的本地维；用 `ACTION_STATS` 的 `q_low`/`q_high` 分位边界 min-max，缺边界回退物理空间 z-score（`phys_mean`/`phys_std`），再缺恒等 + warning），**其余维保持物理量纲**（关节 rad、EEF pos 米、rotvec 弧度、底盘 twist）。agibot 的 reader 内置全维 z-score 由策略按条目烘焙的 `reader_z_mean`/`reader_z_std` 先逆变换还原物理量纲（不动 submodule，build 期 ranges 的归一化单位不受影响）；denormalize 严格对称、输出回 reader 空间（下游评估/监控零改动）。

动作目标表示由 `model.wm.action_target_repr` 选择（同轮改造，B1/B2 对齐 MotusBrain）：

- **`absolute_native`（默认，旧行为）**：绝对坐标 + 各本体原生旋转表示，scatter 即逐维拷贝。
- **`relative_eef_rot6`**：EEF 位姿维动作**相对条件帧 state**——位置 local 空间直减、旋转 `R_rel = R_sᵀ·R_i`（论文相对 EEF；仅作用 `eef_*_pos`/`rot_groups` 维，关节、底盘、夹爪、灵巧手维不参与）；各本体原生旋转（agibot rotvec / robotmind quat/rot3 / egoverse quat）经 `models/action_repr.py` 统一转 **6D 训练目标**，写入 `eef_*_rot6` band（`unified_rot_groups` 接管，这些本地维 dim_map 须为 -1）；20260815 起 state token 已移除——state 不进 token 序列，仅作上述相对化的锚点（scatter 侧 state 的 rot 仍写绝对 6D 供参考点语义，但不再进网络）。推理输出端 `_gather_native_actions` 自动还原（pos 加回 state、`R_abs = R_s·R_rel` 正交化后转回本地原生表示），再反归一化回 reader 空间。

统一 action 空间的 scatter 在归一化与目标表示变换之后、模型边界完成（`UBT_WM._scatter_to_unified` 按 `robot_layout` 的 per-robot `unified_dim_map` 语义槽位映射把 `[B,..,dim_r]` 逐维写入 `[B,..,U]` 零张量，U = `common.unified_action_dim`；dim_map 值 -1 = 摘除该本地维（修复 #7，如 agibot 灵巧手占位维——reader 输出恒 0、烘焙 stats 陈旧的平凡常数目标），不进 scatter/loss mask，推理输出端重建为 raw 0；未注册 dim_map 的旧配置回退 offset 前填并 warning），数据管线零改动。各源实证维序（槽位分配依据）：agibot_beta 26 维 EEF = 每臂 `[pos xyz, rotvec, 夹爪(mm), 灵巧手占位×6]`（`motus_data/datasets/agibot_common.py`）；robotmind tianyi/tienkung 16 维 = `[左 xyz+quat, 右 xyz+quat, 左夹爪, 右夹爪]`、ark 14 维 = `[左 xyz+rot3, 左夹爪, 右 xyz+rot3, 右夹爪]`、arkmobile 20 维 = ark 布局 + 底盘 twist 6 维（`motus_data/datasets/robotmind.py` 的 `state_action_keys` 顺序即拼接顺序；quat 分量序与 rot3 定义仓库无文档，rot_groups 默认 quat=xyzw、rot3 按 rotvec 处理）；egoverse 14/16 维 = `[左 xyz+quat(wxyz), 右 xyz+quat(wxyz)]`（eva 另含双夹爪）。egoscale 24 维 = `[head xyz+quat(xyzw), head_valid, 左 xyz+quat(xyzw), 左_valid, 右 xyz+quat(xyzw), 右_valid]`（quat xyzw 经 20260817 集群抽检确认——T_cam=T_head⁻¹·T_world 恒等式判别；head 与 validity 维 dim_map -1 摘除，validity 仅供 unified_validity_gates 门控；20260817 起读 world_eepose 世界系绝对位姿）。robotwin 四本体 14 维 qpos（关节空间）20260815 起剔除（无 EEF 字段）。
