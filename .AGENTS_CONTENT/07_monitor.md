# 训练监控（libs/motus-monitor/，包名 motus_monitor）

自包含实时监控库（详细用法见 `motus_monitor/README.md`）：

- **架构**：训练侧 `MonitorLogger`（`motus_monitor/client.py`）把配置快照/每步指标/事件/系统负载写成 append-only 分块 JSONL；`python -m motus_monitor serve` 起 Web 服务（Flask，仅 server 侧依赖，训练侧 client 仍 stdlib-only；REST + SSE + 原生 JS 前端 `motus_monitor/web/`），经 SSH 字节级增量同步（`motus_monitor/sync.py`，远端只需 python3，复用 `~/.ssh/config` ControlMaster，BatchMode 免密）。benchmark 标注写本地 `annotations/` 并自动回传集群。
- **独立服务/局域网部署**：`serve --public --san <IP/主机名>` 起 HTTPS 主站（内部 CA 证书，`motus_monitor/certs.py` 用 openssl CLI 签发，私钥 0600 不下载；DN=`O=Ubtech/OU=chen.liao/emailAddress=chen.liao@ubtrobot.com`；**SAN 漂移自愈**：启动发现证书缺当前 SAN 或无 SAN 扩展即自动重签——Chrome `NET::ERR_CERT_COMMON_NAME_INVALID` 多为此因；CA DN 变更=换 CA，客户端须重新导入 ca.pem）+ 账户登录（`motus_monitor/auth.py`，users.json scrypt 哈希，session cookie Secure/HttpOnly，登录/注册按 IP 限流，默认不发 CORS 头）。**所有模式（含 local）都强制登录**（除 /login、/register、/static 外 API 401/页面 302；`--also-local` 免登录通道已移除）；**首个注册账户自动批准**，其后注册 `status=pending` 需管理后台批准。Host 白名单=`HostAllowlist`（启动 SAN ∪ 管理后台追加项，追加即时生效并持久化 `access_addresses.json`，添加时同步重签证书；证书重启生效）。主页顶栏有用户 chip + 登出（`GET /api/auth/whoami` 探测并返回当前查看根，`GET /logout` 清 session）。**每用户 workspace**：查看根与网页自加同步远端隔离持久化在 `<data_root>/workspaces/<user>/`（workspace.json + data/，serve 重启按此恢复各用户引擎，引擎带 `owner` 归属；旧全局 `.added_remotes.json` 仍兼容恢复），读模型按请求解析 `state.request_root()` + `registry_for(root)`（Registry 按路径缓存共享；history/catalog 内存缓存为容量有界 `_LruCache`（history=16/catalog=32），键含根前缀——旧版裸 dict 永不淘汰曾致 serve 内存无限增长；**切片类缓存 20260817 起改字节预算 `_BudgetedCache`**（切片瓦片/索引/stats/响应三缓存共用一名义：内存只存序列化 blob 按真实字节记账，硬预算默认 5120MB，`--slice-cache-mb`/`MOTUS_MONITOR_SLICE_CACHE_MB`；超预算 LRU 溢写 `<启动目录>/.cache/slices/<sha256(键)>.pkl.gz|.raw`，磁盘容量默认 4×，`--slice-disk-cache-mb`/`MOTUS_MONITOR_SLICE_DISK_MB`，键含数据指纹/桶版本、按哈希键懒加载回填；详见"训练集预览"条）；**空闲回收 20260818 起**：缓存原只在超预算/容量时逐出，空闲驻留不降且 glibc 不还内存给内核（RSS 只涨不跌）——reaper 守护线程（`ServerState.start_reaper`）每 `--cache-reap-s`（默认 300s，`MOTUS_MONITOR_CACHE_REAP_S`）把超 `--cache-idle-s`（默认 1800s，`MOTUS_MONITOR_CACHE_IDLE_S`，0=禁用）未访问的缓存条目逐出内存（脏 blob 照常溢写磁盘懒回填、LRU 条目丢弃重算，语义无损）+ 清理超龄 `_slice_locks`，随后 gc + `malloc_trim(0)` 让 RSS 回落（默认开，`--no-malloc-trim`/`MOTUS_MONITOR_MALLOC_TRIM=0`，非 glibc 静默跳过；配置文件 `cache.idle_s/reap_s/malloc_trim`）；每轮记日志（逐出条数/字节/VmRSS）进 server.log）；覆盖率 catalog 缓存与查看根无关、统一在启动目录 `.cache/`）。管理后台（`motus_monitor/admin.py` + `web/admin.html`）**只绑 127.0.0.1**（默认 8378，public 时跟随开启）：CA 下载/Ubuntu 导入说明与脚本导出/证书重签/账户增删与注册审批/访问地址管理/状态查看/helper 手动重启/**服务日志**（serve 启动给 root logger 装 `logs/server.log` RotatingFileHandler 10MB×5 + `motus_monitor/logbuf.py` ring buffer 2000 条；页面级别/关键字过滤 + 自动刷新，`GET /admin/api/logs[/download]`）。JSON 配置文件 `--config`（`motus_monitor/config.py`，默认值=当前部署，CLI 优先），`remotes` 列表支持多远端合并同步（状态 `.sync/<name>.json`；首个命名远端首次启动自动接管旧版单远端 `.sync/state.json` 并改名退役；fetch 按 128 文件/64MB 分块、逐块落盘，大 backlog 可断点续传；**state 只记已落盘字节且每周期按本地真实文件大小自愈校验，脏 state/本地文件缺失自动补拉**；engine.status 暴露 `phase`/`pull_done_*`/`pull_pending_*` 进度字段，前端顶栏进度条展示），dataset 预览挂 `preview:true` 远端。
- **开关**：YAML `monitor.enabled`（stage1/stage2/micro 已开启）或 `MOTUS_MONITOR_ENABLED=0/1` 覆盖；关闭即完全 no-op。所有调用经 `_monitor_call` 容错包裹，绝不影响训练。
- **数据目录**：默认 `<仓库上一级>/motus_monitor_data/`（不可写回退 `~/.local/share/motus_monitor_data/`），`MOTUS_MONITOR_DIR` 覆盖。集群上（20260816 起）即 `/code1/llm_team/chen.liao/ThinkerWM/motus_monitor_data/`。**不要提交 git**。
- **run_id**：存 `<checkpoint_dir>/.motus_monitor_run_id`；弹性重启/auto-resume 续写同一 run；多 rank 由 rank0 生成并 broadcast。新 run 从 resume/finetune ckpt 路径反查父 run（`find_parent_run_id`）构成 ckpt 树。resume 重跑同 step 会在 JSONL 重复（append-only），status 记录 `lineage_base_step`，前端隐藏基点后旧记录并按 step 去重、后写胜出。**重启但非 resume（从 0 重跑）时 `lineage_base_step=0`**：旧 attempt 的 metrics 与 system/GPU（按 `attempt_started_ts`，前端 `sysKeep`）全部隐藏；首次运行为 null 并清除陈旧值。
- **节点标识**：系统流按节点分 `system/node<N>/`（N 取 `NODE_RANK`/`GROUP_RANK`/`JOB_COMPLETION_INDEX`，无则 hostname-localR）+ `node_info.json`。monitor 在模型/数据初始化前创建，初始化失败节点也有流；node 缺失时 grep 该节点 pod 日志 `monitor: run_id=` 看 `data_root=` 是否回退 pod 本地。坑：路径探测曾因固定文件名并发竞态失败——已改 `tempfile.mkstemp` 唯一文件名，勿再引入共享固定文件名探测。
- **集成点**：`train/train.py`（`_monitor_call` + step 记录/ckpt/事件钩子；monitor 在 resume 解析后、模型创建**前**创建，`add_timing_event` 上报初始化阶段，run 状态 initializing → running）、`train_debug/micro_train.py`。rank0 写指标；每节点 local_rank0 写系统采样；**所有 rank 写训练切片**（`log_slice_record` → `slices/rank%04d.jsonl`）。前端默认亮色主题（localStorage 可覆盖）。
- **本机启动**：`python -m motus_monitor serve --port 8377 [--remote user@host:/path --ssh-args "-J jump -p 10023"]`；辅助：`doctor`/`sync-once`/`demo-data`。
- **查看路径切换**：网页顶栏"📂 查看目录：" chip 弹窗分**本机/远端（H-Server）两模式**（有 ssh 远端默认远端模式）。**每登录用户独立 workspace**（`<启动目录>/workspaces/<user>/`：查看根 + 自加远端，互不影响）。本机模式=`/api/browse` 只读浏览（**只列目录名，不读/下载文件内容**）+ `POST /api/data_root` 切换**自己**的查看根；**远端模式**=经一次性 SSH（`python3 -c` 短进程，远端零安装，同样只列目录）浏览远端文件系统，`POST /api/remotes` 把选中目录加为**自己 workspace 的**同步远端（复用参考远端 target/ssh_args，engine 名 `<user>--<slug>`、拉进 `workspaces/<user>/data/` 并把该用户查看根切过去，持久化 `workspace.json` 重启恢复，同用户内按 target+path 去重；旧全局 `.added_remotes.json` 兼容恢复）。后台守护线程低负载浅扫（30s 首扫/10min 轮/深度≤2/异常静默）本机候选位置 + 各 ssh 远端（远端数据根及父目录，按 target+path 去重后扫描），`GET /api/known_roots` 返回 roots+remote_roots，弹窗快捷列表点击本机项=切查看根、远端项=加入同步。
- **训练集预览（dataset tab）**：`/api/dataset/*` 经 SSH 托管的集群侧 helper（`remote_preview_helper.py`，按内容哈希传集群 `/tmp` 拉起，不依赖集群检出）按需解码；机器人→任务两级树、进程池（`--dataset-workers` 默认 2）、`&stream=1` 实时进度、helper EOF 自退 + `PR_SET_PDEATHSIG` + `--idle-timeout` + server 内看门狗（每 20s 探活，失败整池重建，退避至 120s）；切片只存索引（step_record 带 `episode_ids`/`frame_indices`/`action_video_fps_ratios`），`/api/dataset/selection` 解码（state/action 按 layout 重建）；**训练切片全 rank 记录**：每 rank 把各自 batch 切片（+node/gpu/rank）追加写 `runs/<run_id>/slices/rank%04d.jsonl`（train.py/micro_train.py 均接，与 step_record 同间隔）；`/api/runs/{id}/slices` 有 slices/ 目录时按 **step→node→gpu** 树返回（分页单位=step，同 (rank,step) 后写胜出），旧 run 回退 rank0 metrics 流原结构；rank 文件按 append-only 做**增量尾部解析**（仅读新增字节、逐行流式解析不整读，截断自动重置重扫，按 (root,run_id) 锁序列化并发刷新）；**切片存储为 (step//128, rank) 瓦片分片 + 懒加载**：内存常驻仅每 run 轻量索引（{step: 切片数}+增量解析状态），展开瓦片进 `_BudgetedCache` 按需加载；瓦片与写入序对齐（逐 rank 文件解析、文件内 step 基本递增），瓦片跨边界即 finalize 落桶，解析峰值≈单瓦片；`steps_only` 走索引零瓦片加载，分页只物化页内 step 涉及的瓦片，stats/by_ckpt/by_source/top_episodes 全量聚合逐瓦片流式累计（瞬时内存=单瓦片；stats 帧集/区间用 `array('i')` 紧凑收集 ~4B/帧替代逐帧 set(int)），聚合结果按 (各 run 数据指纹, ckpt 段, catalog TTL(1h) 时间桶, step 范围, source 过滤) 缓存（durable 写穿，重启免重扫），桶丢失（磁盘清理）自动全量重解析自愈，`steps_only` 请求提前返回不算 stats；旧 metrics 流路径按 (chunk_idx,size) 逐 chunk 增量解析，训练中追加只重读尾部 chunk——20260817 初版优化（计数 LRU + 增量解析）前每个请求都全量重算逐帧 set 统计/重扫全流，本次（同日二改）解决计数 LRU 控不住 GB 两遍各半，detail=已处理/总切片数，总数来自索引零瓦片加载）→范围统计 85–95%→组装分页 95–100%；缓存命中的阶段直接跳过、条向前跳；每 tick 同时发兼容 `PRG <frac> <阶段名>` 行；报告节流 5Hz、阶段切换/完成强制发；ETA 按全局 frac 线性外推），前端切片面板显示确定性进度条+明细行（阶段/百分比/文件或切片计数/剩余约 X，PRGJ 缺失时回退旧 PRG 显示）；`stats` 含每源计数/占比 + 实际喂入帧口径（喂入/去重/重复；另保留窗口区间时间轴跨度供 tooltip，catalog 有 fps 附秒）+ 覆盖率（分母=run 配置 `dataset.sources`；catalog 优先经 helper `catalog_index` op 拉取（gzip blob，磁盘缓存 coverage/ TTL 1h），本地文件兜底；source 名须与 catalog 名一致，micro 的父名 robotwin/robotmind 对不上会落 missing 标注）；`lineage=1` 沿 parent 链累计祖先 run。前端：step 折叠树（默认展最新）、覆盖率百分比条可展开 episode 明细、"历史累计"开关；切片面板进入/换 run 自动加载并默认选中末尾"最新"段（手动选段后失效）；缓存 `<data_root>/.cache/dataset/`；CLI `--no-dataset`/`--dataset-local`（本机，默认扫 `micro_data/catalogs`）/`--dataset-repo`/`--dataset-workers`/`--slice-cache-mb`（切片缓存内存预算，默认 5120）/`--slice-disk-cache-mb`（溢写磁盘容量，默认 4×）；详见 README。
- **约定**：新增指标字段直接加进 step_record（前端按名字容错）；`.jsonl` 一律仅追加（同步按此尾部增量），其他 JSON 小文件整体重写。
- **dataset 维度语义名**：helper `_dim_names` 从 catalog 元数据提取 action/state 逐维名（modality schema `feature_names`：agibot_beta/libero 逐维；`key_order_names`/episode meta `state_action_keys_order`：robotmind per-key，有 `field_dimensions` 时展开），经 `episode_info`/`action_state`/`selection_preview` 透传 `action_names`/`state_names`；前端维度开关 chip 与 action CSV 表头用该名称，缺失或长度不符时回退 `a{N}`/`dim_{N}`。
- **耗时检查点**：非固定 schema，前端按数据自动分组（`*_seconds`=训练循环，`model_*_seconds`=模型内部，`stage_seconds.*`=自定义），改检查点集合不用动前端。模型内粒度由 `model.timing_level` 控制（1=分支级，2=+逐 block、有 CUDA 同步开销）；埋点用 `motus_monitor/timing.py` 的 `timed_section`/`block_timing`（训练侧专用，server 不 import）。
