# 配置

所有训练参数在 `configs/` YAML。各节：`common`（维度/帧数/分辨率）、`dataset`（`type: indexed_mix` + 带权重 `sources:`）、`model`（wan/vlm/wm 子配置、checkpoint 开关、损失权重、`stage1_video_only`）、`training`、`system`（worker、就绪批次队列）、`diagnostics`、`logging`、`resume`/`finetune`。batch size、分辨率、队列深度、worker 数、checkpoint 间隔、损失权重**优先改 YAML 不改代码**。

**配置/启动脚本命名规则**：`stage<N>_<dev 分支日期>_v<M>`——**配置名必须与当前 dev 分支一致**（如 `dev/20260818` 分支 → `stage2_20260818_v1`），同一分支周期内以 `_v1`/`_v2`… 迭代标签递增；**不按修改当天日期另开日期序号**。`configs/` 与 `k8s_job_script/` 同名成对创建。**配置名称必须询问用户拍板，新建文件还是修改原配置也由用户决定**——助手不得自行命名或自行决定覆盖既有配置。

**训练 seed 规则（20260818 起）**：`training.seed` 决定整条数据采样链的确定性——`WeightedIndexedBatchStream` 跨源调度、`EpisodeGroupedBatchSampler` 组内洗牌、`SamplingRangesPool` 窗口起点全部是 (seed, epoch, index) 的纯函数（`data_prepare/sampling_ranges.py` `SamplingRangesPool.generate`），**同 seed 的不同运行会逐 batch 看到完全相同的训练数据**。因此：**每个新配置文件必须显式写 `training.seed` 为一个新的非零值**（建议取建配置当天日期，如 `20260818`；同一配置周期内 `_v2` 迭代也要换新值），禁止留 0、禁止复用已用值。代码兜底默认 `20260818`——`train/train.py` `create_dataloaders` 与 `train_debug/micro_train.py` 均从 `config.training.seed` 读取、缺省非 0；新建训练入口禁止硬编码 `seed=0`（调试/冒烟脚本可显式传 0）。改 seed 只改变采样序列，不影响 ranges/catalog；`periodic_eval.seed`（评测窗口/生成噪声种子，固定 `20260805`）与训练 seed 无关，评测刻意固定以跨轮可复现。

## pool spec 机制

`pool` spec 经 `pool_providers.py` 解析为 pool 工厂 callable，经 motus_data `SupportsSamplePool` 注入点（`open_training_data` 的 `sample_pool` 参数）进入管线；selection 训练进程内动态生成（同 (seed, epoch, index) 跨 rank/worker 确定性一致，`set_epoch` 推进换窗），不落盘。新增选择方式：写 `SupportsSamplePool` Pool 类 + `register_pool_builder`，YAML `pool: {type: <名>, ...}` 即可，库零改动。

## sampling_ranges 窗口布局

ranges metadata `layout` 键，缺省 `consecutive`：

- `consecutive`：视频连续 N+1 帧，state=s·ratio，动作 (s·ratio, (s+N)·ratio]（agibot 6 倍动作频率时视频与动作同跨度；1:1 源上动作视界为视频 ratio 倍）。
- `video_stride`（`--video-stride`，旧 1:6 语义）：视频每 ratio 帧抽 1 帧 [s, s+r, ..., s+N·r]，state=s。动作起点由 pool 的 `action_start_offset` 控制：缺省 1 保持旧区间 [s+1, s+N·ratio]；RoboTwin/LeRobot 的 `action[t]` 是 state[t] 后发出的命令（且数据满足 action[t]=state[t+1]），应显式设 0，使用 [s, s+N·ratio-1]。新建库时同步传 `build_sampling_ranges.py --action-start-offset 0`，使建库边界抽检、离群窗口过滤和 metadata 与 runtime 一致；旧库没有该 metadata 键，仍允许由 pool 显式选择 offset。短 episode 索引 clamp 到 L-1（**末帧填充**，上限以 `episode_len` 列烘焙；旧 ranges 无此列按 None 不 clamp）。`--max-stride K`（20260813 起，仅 video_stride）追加烘焙 `max_stride` 列：该起点可用的最大时长倍率 k（窗口跨 s..s+N·ratio·k 不越界且不落入剔除区），运行时 pool 带 `stride_max: K` 时按均匀 k∈[1, min(K, max_stride)] 采样变倍率窗口（k=1 退化为原行为；动作索引同步放大为 N·ratio·k 连续步）。

## 重要约束

- **首帧是干净条件帧（teacher forcing）**：训练首帧 latent 不加噪、其全部 token（整帧 h×w 个，非单 token）时间标签置 0、loss mask；推理每步强制替换回干净首帧 latent。uni 分支 und token（干净 VLM 条件）时间标签同样置 0。σ 调度 per-modality（D1，20260811 对齐 MotusBrain）：video 侧训练采样与推理 σ 网格共用 `model.wm.flow_shift`（默认 5.0；训练标签 = shift 后 σ×1000），action 侧用 `model.wm.action_flow_shift`（默认 None = 跟随 flow_shift 旧行为；生产 1.0，独立 scheduler 采样 + 推理 action σ 网格，需 `independent_modality_noise=true`；共享噪声路径训练不使用它——与推理网格分布不一致，`__init__ 会 warning）——**改 shift 训练/推理一起改**。
- **文本条件 dropout 与 CFG（20260818_v2 起改版）**：逐样本 condition dropout 已并入模态 dropout——无条件分支训练由 `model.wm.modality_dropout_prompt`（生产 0.1，batch 级、跨 rank 一致、每 update step 重采）单一机制承担；`model.condition_dropout_prob` 字段保留但**弃用**（代码不再读取，非 0 仅触发 warning；step_record 不再有 `condition_dropped_fraction`）。**无条件表示改为 tokenizer-only token 嵌入常量（20260818_v2 用户拍板）**：`UNCONDITIONAL_VLM_MESSAGE`（空文本）只经 VLM tokenizer + embedding 层、不过语言模型（`und_branch.get_uncond_vlm_feature` 懒构建常量）；训练 drop_prompt 步、推理 CFG uncond 前向（`inference_step(guidance_scale>1)`，`ubt_wm.py` 空文本 encode 自动路由到同一常量）、以及 encode 遇任何空消息统一该表示（训练/推理一致；可学习 null token 仅保留给推理期 prompt 缺失语义）。推理 `inference_step(guidance_scale=...)`（默认 1.0=关闭、单次前向；>1 时每去噪步 cond/uncond 双前向合并**仅 video 速度场**——修复 #1：action 默认不做 CFG，`action_guidance_scale` 默认 1.0，!=1.0 仅为消融保留），评估路径经 `model.inference.guidance_scale` + `model.inference.action_*`（`train/sample.py`、`scripts/eval_video_ckpt.py`、periodic_eval 均读取；生产 video 5.0 / action 1.0）。**CFG 只在训过无条件分支（modality_dropout_prompt>0）的 ckpt 上有意义**。字段级 prompt dropout：`model.vlm_field_dropout_prob`（默认 0；micro 0.2 / 生产 0.1）——**`vlm_text_rewrite: true` 时为输出侧语义（20260818_v2 起）**：对改写输出文本按字段行（Task/Action/Scene）逐样本独立伯努利 drop（整行移除、全中时随机保留 1 个字段行；`utils.vlm_utils.apply_field_dropout_to_rewrite`），在改写磁盘缓存**之后**作用、不产生新 cache key，仅训练态，随 prepare 级消息重建每 batch 采一次、跨 `train_steps_per_vae_encode` 复用步共享；rewrite 关闭的旧配置仍为输入侧旧语义（消息重建时从 `build_vlm_task_message` 四字段格式指令整字段移除，字段标签与顺序不变）。`build_vlm_task_message` 会先经 `strip_robotwin_view_preamble` 剥离 robotwin 三视角样板文前缀（修复 #8：生产 catalog 文本含长样板文且非 aloha 源错写 "The aloha robot"，只留任务句进格式指令）。
- **uni 分支注意力**：cross-attn（(video,action)↔und 相互）无 RoPE；self-attn 中 action token 的 RoPE 时间频率按 `action_t_downsample/(video_action_freq_ratio×4)` 缩放（4 = VAE 时间 stride），与 video latent 帧时间轴对齐；20260815 起 action 序列无 state 前缀 token（state token 已移除，见下条），action token i 在时间位 i。und 被影响通路：uni 每 block 的 B→A cross-attn（und 作 Q 查 video/action）+ uni 输出 und 作为 video/action decoder 的 cross-attn 条件。
- **und token padding mask（评审 #1）**：`UndBranch.encode` 返回的 `seq_lens` 是逐样本**真实（未 padding）长度**（VLM attention_mask 求和）。所有把 und 当 K/V 的注意力都用它 mask padding：video/action 分支 encode/decode 的 `context_lens`、uni self-attn und↔und 与 cross-attn A→B 的 k_lens。und 作 **Q 侧一律全长**（`q_lens=None`，flash_attention varlen 输出按 (B, Lq) unflatten）。验证见 `scripts/test_und_padding_mask.py`。
- `num_video_frames` 由 adapter 常量决定：每条 selection 必须 `num_video_frames+1` 视频索引 + 1 state 索引 + `num_video_frames*ratio` 动作索引（adapter 逐样本强制校验）。ranges 把 N/ratio 烘焙进区间（运行时与 `common.num_video_frames` 交叉校验）；改序列长度需重建 ranges。
- **action 时序下采样（20260814 起）+ state token 移除（20260815 起，stage2_20260815_v1 头注 3）**：`model.wm.action_t_downsample` 与 ratio 对齐（6）：动作 T=N·ratio=288 步**无裁剪**经 stride-d Conv3d 分组成 T/d token，要求 T % d == 0；20260815 起序列首位 state token 移除（`state_embedding` 删除、decoder 不再跳过首位、uni 分支 `ta[:,0]=0` 特殊位移除，action token i 占 RoPE 时间位 i）——state 不进 token 序列，仅在模型边界作 delta-EEF 相对化锚点与归一化输入（`_scatter_to_unified`/`_gather_native_actions`），batch 契约 `initial_state` 不变；`MotusConfig.action_chunk_size` 公式同轮修复为 N·ratio=288（旧 (N+1)·ratio-1=293 是 consecutive 布局残留，293%6≠0 触发推理路径 `T % t_downsample == 0` 断言）。decoder 输出 = 每 token `Linear(dim, d·U)` 共 T 步（loss/推理/数据管线不变，σ per-sample 语义不破）。旧 ckpt 热启动经 `load_state_dict` 的 `_remap_action_t_downsample`：embedding 时间核 1→d tap 填旧权重/d（均值池化初始化）、unembedding 输出维 U→d·U 平铺；`state_embedding`/`state_unembedding` 旧键由 `_LEGACY_STATE_DICT_PREFIXES` 丢弃。（历史：20260814 前 ratio>1 要求 td=1——旧划分为裁 ratio-1 步 + state_unembedding 补步，283=质数只能 td=1。）
