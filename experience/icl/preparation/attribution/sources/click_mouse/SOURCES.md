# Sources and permitted evidence

**No external web sources, benchmark writeups, or additional learned models were used.** No other agent was invoked. There were no model weight updates.

- **Provided task specification (`input/task.json`).** Used for the exact goal (“Move the mouse to the purple mouse pad and click the left mouse button.”), single-arm 22-value action layout, 23-value proprioception layout, 30 Hz control rate, camera aliases, and `rand_full` regime. This package restates the information needed at runtime.
- **Trusted released-demonstration reader**, invoked only with `list`, `arrays DEMO_ID`, and `video DEMO_ID CAMERA`. Read all 100 demonstrations, IDs `0000`–`0099`, totaling 46,176 steps. Numerical files contained only `state`, `actions`, and `timestamps`. Used all numerical sequences, both RGB streams for corpus-wide samples, complete base-video color traces, early wrist sequences for geometric triangulation, and dense representative phase views. No privileged object coordinates were available or used.
- **Provided pinned robot reference README and `mjcf/panda_allegro_copy.xml`**, upstream commit `8d23b0fab23b17a58c4b55f3942e17013aaf8267`. Used solely for the attachment-site/hand-camera transform, 60-degree wrist-camera vertical field of view, hand joint order/axes/limits, palm mount, link lengths, and fingertip collision capsule geometry. The camera projection and hand FK were checked against visible robot landmarks. The README mentions a `robot.json` that was not supplied; layout information instead came from the task specification and released arrays. No task scene was inferred from robot meshes or source code.

`primitives.npz` retains only the public actions and proprioception of demonstrations `0012`, `0014`, `0030`, and `0077`; timestamps are unnecessary because they are uniformly 30 Hz. `primitives.json` records the source IDs, manually interpreted phase boundaries, visually detected monitor changes, and RGB-derived source geometry. Reference images are selected released RGB frames: `initial_geometry.jpg` is annotated demo `0012` frame 10; `phases.jpg` uses demo `0012` frames 50, 90, 130, 170, 200, 217, 245, 284 from both cameras; `button_view.jpg` annotates the left button and wheel in demo `0077` wrist frame 225.

Pad size/height, mouse geometry, phase labels, and display-change cues are observational estimates from these sources, not evaluator conditions. Validation used only released demonstrations and numerical consistency checks. No evaluator, test seeds, test results, or future episodes were accessed. Retargeted controls remain untested in new task episodes.
