# ThinkerWAM-RSI 具体感知能力与实施顺序

版本：2026-10-21 / calibrated-rgb/v1。补充框架 §5.6；接口细节见 [interface.md](../tools/perception/interface.md)，执行笔记见 [notes.md](../tools/perception/notes.md)。

## 本次补齐的内容

此前 Measure 只有回调入口，没有具体感知算法、参数或几何返回值。本次已有可调用的六个工具：像素射线、双视角三角测量、RGB 水平平面测高、实测平面定位、颜色区域分割、区域质心的平面投影。统一输出快照/相机/标定身份、坐标系、单位、数值诊断、未知原因及独立操作检查。

几何输入独立于 WAM 输入：读取未拼接、未缩放、已去畸变的单相机图像和与之匹配的 K/T。新增 CalibratedRGBAdapter 做显式字段和约定转换；相机元数据缺失时返回不可用，不能从任务资产读取桌高或物体位置补齐。

接口已接入 Agent 的参数化 Measure、工具说明发现、JSONL 结果和共享几何结果缓存。measured_point_stage 将经过独立验证的当前三维点交给已有 direct 规划器，继续遵循审核和单一执行器；没有另起一套 Agent 主循环。

## 一次具体的感知与动作流程

1. Agent 从原始相机图像识别任务目标；可用颜色分割给出候选区域，语义识别仍由 Agent 或后续检测器完成。
2. 对选定桌面/平顶区域调用 measure_plane，或为目标特征点选择两视角像素调用 triangulate_point。
3. 检查数值诊断和输入关联。表面不能确认、对应点不明确或几何退化时，先重观察或补视角。
4. 使用当前 measurement_id 读取三维点；独立验证 target_identity 和 geometry_applicable。measurement_computed 不能替代这两项检查。
5. direct 规划器把世界点转换到机器人基座/TCP 和实际动作契约，提出接近或局部操作；统一执行器执行。
6. 用新的图像和状态验证操作。机器人移动后旧 measurement_id 失效，需要重新测量或由后续显式物体跟踪模块建立新的状态。

该流程的数值计算、报告、只读调用、参数传递和进入 direct 的门槛已有 CPU 集成测试。现场相机绑定、真实目标验证器、IK/抓放控制器和真实任务成功率仍未验收。

## 失败诊断、工具修复和经验复用

新工具返回具体原因：ray angle 不足、两射线不一致、相机后方交点、弱纹理、视野重叠不足、峰值多义/位于边界、时戳或标定不一致、过期测量引用。它们帮助选择重新标定/测量、修改区域、补视角或修工具，而不是把失败都送入 WAM 训练。

采集接线后，每个回合应保留 native RGB bundle、调用参数和结果。目前已提供 save_bundle，工具调用和结果已进入 runner 日志；原始图像的逐回合自动留存仍需现场适配器接入。优化器修复工具后，先用 scripts/measure_geometry.py 重放原故障，再跑独立样本和机器人回归；代码、接口和 notes 必须共享明确版本。几何单元测试通过不能直接发布新操作能力。

scripts/build_geometry_experience.py 使用现有 ExperiencePackage 格式封装指定接口、笔记、代码和测试。输出为候选资源包；不会自动给所有任务启用，也不会绕过 Core 的验证、发布和任务映射。算法限制笔记和经过真实机器人验证的操作经验应分别标注证据。

## 后续能力按依赖逐项实现

第一步是现场 RGB/K/T/FK/时戳接线，并用实测标定板或具有独立尺度测量的物体检查重投影和毫米误差。保存一小批真实 bundle，为各工具建立正例、困难例、拒绝例。此项优先于扩大工具目录。

第二步是语义/实例感知和跨视角关联：Agent 标点、可插拔分割模型、特征匹配、遮挡处理。输出 image-local region ID 和关联证据，不直接宣称对象永久身份。相接同色物体和无纹理目标是当前颜色阈值工具的已知边界。

第三步是物体局部几何：经确认的顶面高度/轮廓、容器口与边缘、长轴/夹爪姿态、相对 TCP 的被持物体位姿。当前区域质心投影不代替这些能力；倾斜表面和复杂接触需新模型或算法。

第四步是操作验证与主动感知：物体随夹爪移动、滑移、稳定放置、插入/接触进展；根据可观测性选择补视角。补视角经 direct 执行并计算动作预算。是否使用深度、触觉等由实际允许观测决定。

第五步才是 WAM 预测辅助几何决策：用任务局部量比较预测与实测，验证能否改善动作选择、早停、恢复和观察调度。预测不能当作已测几何。

## 验收标准与已知边界

目前测试使用解析相机及已知水平面生成的图像，不能宣称真实机器人达到毫米精度。plane_sweep 的 step/8 是搜索分辨率；ray_gap 是射线一致性；两者都不是三维定位误差保证。NCC 不是概率置信度。

真实感知验收需单独采集带独立参考测量的数据：标定用重投影误差（像素）；三维点用欧氏误差的中位数/P95（毫米）；平面用高度绝对误差（毫米），后续一般平面增加法向角误差（度）；区域分割用人工标注的 IoU；跨视角对应用人工审核准确率。所有几何误差必须同时报告有效输出率、unknown 率及错误接受率，避免只统计容易成功的样本。阈值应由具体操作容差倒推并在独立数据上冻结，不能把当前 5 mm 射线间距门槛当作真实定位误差阈值。离线评估标签只用于评估，不能进入 Agent 运行观测。

起始算法仅支持同一快照、已去畸变相机、水平纹理平面和显式目标区域。暂不支持自动全场景三维重建、跨时间三角化、通用 6D 姿态、自动抓持验证、避障或力控。后续每项能力需独立数据和验证，不能用 CPU 替身测试代替 P0–P3 验收。
